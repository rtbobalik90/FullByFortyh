SETTINGS
ESV API KEY
Required to pull live ESV text. Register free at api.esv.org. Without it, the system uses cached default verses.
ANTHROPIC API KEY (AI CHAT)
Optional. Powers the Talk Me Down AI chat. Off by default. When you're ready, paste your key.
CLOUD BACKUP
Auto-syncs all your data to a private GitHub Gist. Survives cookie clears, device resets, and reinstalls.

One-time setup:
1. Go to github.com/settings/tokens
2. Generate new token (classic) → check only the gist box → generate
3. Copy the token and paste below.
Save the token in your password manager too — you'll need it again if you ever clear data.
NOT CONFIGURED
Privacy note: Data is stored as a private GitHub Gist. Only people with your token can access it. GitHub stores it on their servers and theoretically has access. Don't enable cloud backup if that bothers you.
PATTERN ALERTS
Real-time risk evaluation. Surfaces warnings on home/watch when dangerous conditions stack (late night + poor sleep + low mood etc.).
SENSITIVITY
DAILY BRIEF · AUTO-GENERATE
When ON, your daily brief generates automatically after morning check-in.
WEEKLY INSIGHTS · AUTO-GENERATE
When ON, insights auto-generate every Sunday evening after your check-in.
APP LOCK
Lock the app with a 6-digit passcode. No one sees your data without it. Face ID/Touch ID can unlock too. There is no recovery if you forget your code.
THE WATCH · GOAL
Current target streak. Recalibrate anytime — this isn't punishment, it's setting the next stretch.
DAILY READING · CURRENT PLAN
The reading plan you're on right now. Update whenever you switch plans. Leaving these blank just removes the link.
CUSTOMIZE
Pick what's at the top of HOME, what cards show on HOME, and which sub-sections show inside each pillar. Changes save instantly.
STORAGE
Your data lives on this device. Photos and recipe images take the most room. Recipe images now save to a separate, larger pool (IndexedDB) so you can keep hundreds.
DATA
Your data lives on this device. Export weekly so a phone replacement doesn't lose four years of formation work. Import restores from a previous export — useful when moving devices.
